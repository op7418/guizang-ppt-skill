# 主题色预设（Themes）

5 套精心调配的主题色板,保证"电子杂志 × 电子墨水"的美学不垮。**不直接使用用户给的颜色值——色彩搭配错了画面瞬间变丑**。用户有品牌色或 logo 主色时，走下方「用户给了品牌色」流程生成受约束的主题；否则只从以下预设中挑选。

## 使用方法

全部主题已内置在模板的 `GZ:TOKENS` 区块里。选定主题后，只改拷贝好的模板第一行 `<html>` 上的 `data-theme`：

```html
<html lang="zh-CN" data-family="magazine" data-medium="slide" data-theme="indigo-porcelain">
```

不要改 `GZ:TOKENS` 区块，也不要在页面里写颜色值。文字、线条、强调色一律用语义变量：

| 变量 | 用途 |
|---|---|
| `--paper` / `--ink` | 底色 / 主文字 |
| `--text-body` / `--text-secondary` / `--text-helper` | 正文 / 次要 / 辅助文字，对比度已校验，代替 opacity |
| `--line` / `--line-strong` / `--line-subtle` | 分割线 |
| `--accent` | 强调色：色块、细线、圆点、高亮条 |
| `--accent-ink` | 强调色用作**小字**颜色时用它（浅色强调色会自动加深到可读） |
| `--accent-display` | 强调色用作**大字**（标题、KPI 数字）颜色时用它 |
| `--accent-on` / `--accent-on-rgb` | 强调色色块上的文字颜色（黄、绿上是墨色，蓝、橙上是白色） |

### 用户给了品牌色或 logo 主色

不要直接使用这个颜色。运行：

```bash
node <SKILL_ROOT>/scripts/gz-theme.mjs brand "#4D6BFE" --family magazine
```

把输出的 `[data-theme="brand"]{…}` 贴到 deck `<style>` 的末尾，再把 `data-theme` 改成 `brand`。
脚本会把颜色收进本风格精调色板的明度 / 彩度区间，并检查 WCAG 与 APCA 对比度；不达标时会说明原因，这时从下面的预设里选。杂志风会把彩度压到 0.12 以内，高饱和的品牌色会变得更克制（例如 #FF2442 → #b75a59，第一行注释会写明调整）；需要保留鲜艳度时用瑞士风。

## 切换原则

- **一份 deck 只用一套主题**,不要中途换色
- WebGL shader 的默认主色(钛金色散 / 银色流动)适配所有 5 套(经测试可接受)
- `currentColor` 驱动的 border / icon 会跟随 section 的 text color 自动适配,无需额外调整
- 选定主题后,`<title>` 文字和 `chrome` 文案可以强化该主题的语义(例如牛皮纸配"Vol.03 · 秋"这种)

## ❌ 不要做的事

- ❌ **不允许混搭**(例如 ink 取墨水经典的,paper 取沙丘的)——会彻底违和
- ❌ **不要把用户给的 hex 值直接写进页面**——用 `scripts/gz-theme.mjs` 生成受约束的品牌主题；脚本判定不达标时，展示 5 套预设让选
- ❌ **不要直接修改 template.html 里的颜色**——所有颜色都走语义变量,换主题只改 `<html>` 的 `data-theme` 一处

选定主题后在 skill 对话中告诉用户:"用 🖋 墨水经典 / 🌊 靛蓝瓷 ..."并在 deck 项目记录里备注,方便后续迭代时保持一致。
