# Copy-ready talk prompts

Replace the bracketed inputs. These prompts are for talks with spoken explanation,
not general website or poster creation. Existing project decisions remain in
force unless the new request changes them.

## New research or community talk

```text
使用 $research-talk，为 [受众] 准备一个总时长 [时长] 分钟的 talk。

材料：
- 项目/论文：[路径或 URL，以及要使用的版本]
- 代码与数据：[路径或 URL]
- 模板/参考 slides：[路径；哪些页面需要原样保留]
- 个人简介、相关工作和作者照片：[已有材料，可选]

默认英文 slides，中文 transcript；使用 [指定模板] 的视觉风格。
先理解动机和方法，再组织讲述。用真实数据例子、训练流程、计算过程和结果
可视化解释核心思想。需要时加入可手动推进的页内信息流动画，让输入、处理、
输出和反馈关系容易理解；跨页转场保持克制。

中文稿要自然、简洁，围绕研究问题、设计理由、技术步骤和实验证据展开。
不要把“点击后出现什么”“方块怎样填满”写成口播。先用直观的话解释，再接
术语和公式。示意数据与实测结果分开，保留必要的局限和负面结果。

保留现场停顿和交流时间，从同一个内容源生成 slides 和讲稿。若采用 HTML，
优先复用 guizang 或已有演讲者引擎；检查当前预览和观众屏的动画、备注同步。
交付 [例如：独立 HTML、中文讲稿、可重建源码、PDF/PPTX 备用版]，说明验证结果。
信息足够时直接推进；只有关键缺口才提问。
```

## Refine an existing talk

```text
使用 $research-talk，refine [现有 talk 目录或文件]。

这次只修改：[页码/稳定 ID + 具体要求]。
保留：[其余页面、已确认讲稿、原模板、现有动画/演讲者行为等]。

先确认实际内容源和当前页码，不要只改生成文件。把每条要求落实为观众能看懂
的内容或关系，并检查修改后的实际画面。若改信息流或图表动画，检查它在普通
模式、演讲者当前页预览和观众窗口中的真实行为；文字修改不重构运行时。
同步受影响的备注与现有导出文件，并核对授权范围外的内容保持不变。
```

## Refine the transcript across the whole deck

```text
使用 $research-talk，通读 [talk 目录] 的全部 slides，并重新润色中文 transcript。
重点是讲清项目本身：为什么做、方法怎样工作、证据支持什么。

每页围绕它的讲述目的。删除口播里的点击、动画播放、颜色切换和布局操作解释；
可视化负责展示，讲稿负责技术论述。指认真实图像证据的颜色可以保留。
把抽象名词串改成具体操作，首次出现的术语先解释。结果页先说发现，再用少量
数字支撑。保持语气自然，读起来像向同行介绍自己的工作。

核对关键技术区别和结论边界，避免口语化时改变含义。同步独立讲稿、HTML 内置
备注和 PowerPoint 备注。保留已有视觉与运行时；如发现页面上的实质错误，
只做必要修正并说明。
```

## Review only

```text
使用 $research-talk，review [talk 目录]。本次先只报告问题，不修改文件。
检查四件事：科学表述准确、讲述顺序连贯、中文口播自然、页面可读且视觉支持方法。
对涉及动画的页面，再看信息流和关键中间态是否表达正确；不要把表面动效当成贡献。
按页给出真实问题、影响和最小修改建议。区分必须修复的问题与可选审美偏好。
```

## Standalone prompt when the skill is not installed

```text
请制作或修改一个研究/技术 talk：[任务、材料、受众、时长、修改范围]。
以用户选定的模板和当前论文/代码/数据版本为准。默认英文 slides、自然中文口播，
给现场停顿留时间。每页先明确一个听众问题，再选内容、视觉和必要的分步状态。

用真实例子解释动机，用明确节点和箭头表达数据、模型输出、训练信号和参数更新。
动画必须帮助看懂关系或比较；口播讲设计和技术，不讲控件或动画怎样播放。
先解释对象和操作，再引入术语/公式。结果图保持共同坐标、准确基线和单位，
展示下降项，限定联合消融和统计结论。构造例子不得冒充实测结果。

美化时优先处理层级、对齐、字号、留白和证据完整性，保留指定品牌与原样复用页。
既有 talk 从权威内容源修改，保持稳定页 ID；限定页面修改不得影响其他内容。
一份内容源同步 slides、中文稿和演讲者备注。HTML 当前预览与观众屏要同步页/step，
重复状态消息不能重启动画，进入演讲者模式不能改掉用户的动态偏好。
静态导出应展示完整且不重叠的信息；已有 PDF/PPTX/ZIP 同步更新。
用真实渲染和必要的行为检查完成验证，说明验证范围和当前文件位置。
```
